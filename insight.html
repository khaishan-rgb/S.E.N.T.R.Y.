Day-1 Running Time Simulator NO PAST TRIPS REQUIRED

Builds running time from route + live LTA traffic + engineering components, then runs Monte Carlo scenarios. Historical completed trips are optional and used later only to calibrate the model.
Enter a service and run the model. This works before any historical trip has been collected.

Hourly Time Period Report FORMULA · NO PAST TRIPS

Running time for every pair of important stops and every time period, worked out from distance, live LTA road speed, DataMall passenger volume and the dwell / signal formula. Same layout as the operator TPR, with graphs and an Excel download.
Enter a service and generate. First and last stop are always included; tick the stops in between that you want as timing points.
