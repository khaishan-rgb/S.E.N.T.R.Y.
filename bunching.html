    Service Headway Master

    Scheduled headway by service, direction, day type and time. Overrides LTA's frequency band when a row matches (narrowest time window wins).

    Event log

    Bunching and long-headway events, logged only when they last long enough.

    Halfway Optimiser – parameters

    Eligibility limits, recovery rule and score weights. Defaults follow the specification; tune them after operational testing.

    Halfway Optimiser – approved halfway points

    The optimiser only recommends points listed here. Per-point limits are optional (blank = the parameters above).

    Halfway Optimiser – simulation audit log

    Every simulation is stored: time, input data time, bus, delay, all scenarios, parameters and model version.
