Key takeaways

    Simulator parameters

    Defaults for the scenario. The page can override headway, layover and replacement delay for a single run.

    Approved halfway stops

    Only these stops are tested (plus one what-if stop typed on the Simulator page). One row per service, direction and stop.
    CSV columns: service, direction, stop_code, sequence, enabled (a header row is optional; stop_code or sequence is required).

    Simulation audit log

    Each time you press Run simulation the scenario and both outcomes are stored (live re-simulation while you edit is not).
